# Conference-Room-Booking-System

VUT Conference Room Booking System
Overview

The VUT Conference Room Booking System is designed to improve how students reserve conference rooms and meeting venues. Instead of physically going to the library only to find that rooms are already occupied, students can view room availability and make bookings online.

To ensure that bookings are legitimate, the student creating the booking must invite other participants, who are required to confirm their attendance before the reservation is finalized.

Key Features
Student login and authentication
Online conference room booking
Automatic VUT student email generation
Participant invitation and confirmation system
Booking confirmation only after all selected members approve
Real-time room availability tracking
Automatic cancellation of bookings if attendees fail to arrive within 15 minutes of the scheduled time
Objective

The system aims to reduce time wasted searching for available venues, improve the utilization of conference rooms, and provide students with a convenient and efficient booking experience.
